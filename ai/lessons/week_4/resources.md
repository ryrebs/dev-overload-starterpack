# Week 4 Resources

## Must-Read
- **BEIR benchmark** — how embedding models are evaluated for retrieval tasks
- **BGE paper** — how bge-m3 was trained (multi-lingual, multi-granularity)
- **Chroma docs** — collections, metadata filtering, persistent storage

## Reference
- **LlamaIndex retrieval docs** — different retriever types (vector, keyword, hybrid)
- **Pinecone: What is a Vector Database?** — good conceptual overview
- **FAISS documentation** — Facebook's vector library (alternative to Chroma)

## Practice
- Add a second collection for a different document type and query both
- Implement a simple BM25 retriever and compare results to vector search
- Plot the distribution of cosine similarity scores for your actual documents

## What Interviewers Ask
- "How does a vector database work at a high level?"
- "When would RAG fail? When would fine-tuning be better?"
- "What's the difference between dense and sparse retrieval?"
- "How do you evaluate retrieval quality?"
