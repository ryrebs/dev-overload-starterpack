# Week 1 Resources

## Must-Read
- **3Blue1Brown: Neural Networks series** — visual intuition, best free resource
  - "But what is a neural network?" — start here
  - "Gradient descent, how neural networks learn"
  - "What is backpropagation really doing?"
- **Andrej Karpathy: micrograd** — 100-line autograd engine. If you understand this, you understand backprop.

## Reference
- **CS231n Stanford: Neural Networks** — lecture notes, free online
- **Deep Learning Book (Goodfellow et al.)** — chapters 6-8 for theoretical depth

## Practice
- Implement a 2-layer network without looking at the solution
- Add a different activation function (tanh) to `02_neural_network.py`
- Experiment with different hidden layer sizes (try 2, 4, 8, 16 neurons)

## What Interviewers Ask
- "What does a gradient represent geometrically?"
- "What is vanishing gradient and why does it happen?"
- "Why do we need non-linear activation functions?"
- "What's the difference between a parameter and a hyperparameter?"
